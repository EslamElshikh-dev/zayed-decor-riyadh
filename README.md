# زايد للديكورات والدهانات

موقع عربي سريع ومتجاوب لنشاط زايد للديكورات والدهانات في الرياض، مبني باستخدام Next.js App Router.

## تشغيل محلي

```bash
npm install
npm run dev
```

## بناء الإنتاج

```bash
npm run build
npm run start
```

البيانات العامة للنشاط محفوظة في `src/lib/business.ts`، ومحتوى الخدمات في `src/lib/services.ts`. الموقع ينشر صفحات ثابتة، مع ملفات Sitemap وRobots وبيانات منظمة ووسوم مشاركة. الصور التوضيحية مولدة لهذا الموقع وليست سجلًا لأعمال منفذة.

للنشر على عنوان آخر، عيّن `NEXT_PUBLIC_SITE_URL` إلى الرابط النهائي قبل البناء حتى تتطابق canonical وخرائط الموقع والبيانات المنظمة.
